Задача

В каталоге нужны актуальные объекты из CRM, а в обратном направлении — обращения с сайта. Ранняя контактная форма не сохраняла заявки, поэтому у агентства не было истории этих обращений.

Моя работа

  • Сделал каталог и карточку объекта на React и TypeScript. В карточке доступны галерея, карта и контакты агента, если они указаны в CRM.
  • Подключил к сайту данные об объектах и сотрудниках из CRM.
  • Написал сервис приёма обращений. Он записывает заявку и страницу, с которой её отправили, а затем передаёт данные в CRM.
Технические детали

Для каталога я использовал данные объектов и сотрудников из CRM. Обработку форм вынес в отдельный сервис на Node.js.

Поиск по реальным объектам

Каталог и отдельные страницы дают пространство для фотографий, характеристик и расположения.

Интерфейс для разных экранов

Адаптивные карточки, галереи и навигация сопровождают путь посетителя до обращения.

Связь с внутренней системой

API объектов и сотрудников, отдельная обработка заявок и конфигурация сайта.

Результат

Агентство получает вместе с обращением адрес страницы, с которой написал посетитель. Если CRM временно недоступна, сотрудники могут найти заявку в журнале сайта.

До запуска сервиса
Контактная форма не сохраняла историю. Восстановить старые обращения из базы сайта было невозможно.
После запуска
Сайт записывает обращения из 2 форм — обратной связи и рекомендации. Только после сохранения он отправляет заявку в CRM.

В локальной проверке я отправил по 10 заявок через каждую форму. Все 20 сохранились, в том числе две, для которых тестовая CRM вернула ошибку.
