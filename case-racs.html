Управление Windows-устройствами

VK Admin RMS

Разработал систему для поддержки Windows-компьютеров в филиалах. Из панели администратор задаёт общие папки филиала, видит версии службы на компьютерах и может подключиться к рабочему столу для помощи сотруднику.

Задача

На рабочем месте сотрудника должен быть доступ к общей папке филиала, а у руководителя — ещё и к папке руководителей. Поддержке нужно управлять этими настройками и обновлять службу на компьютерах из одного места.

Моя работа

  • Разработал Windows-службу и приложение для сеанса пользователя. Служба получает настройки от сервера, а приложение подключает нужные диски в Проводнике.
  • В панели на React и Electron сделал карточки филиалов и устройств, настройку сетевых папок и удалённый рабочий стол для поддержки.
  • Настроил выпуск обновлений. Администратор публикует версию в панели, а на компьютере программа обновления проверяет пакет и восстанавливает предыдущую версию при неудачном запуске.
Технические детали

Для службы Windows выбрал .NET, для сервера — Node.js, для панели администратора — Electron. Связал их через Socket.IO, чтобы панель получала текущее состояние устройств.

Агент как Windows-служба

Фоновый процесс сообщает состояние устройства и выполняет команды управления файлами и процессами.

Управление с desktop-клиента

React и Electron объединяют список устройств, филиалы, политики, установщики и версии.

Жизненный цикл поставки

MSI-установщик, служба обновления и проверка SHA256 перед заменой версии.

Результат

Настройки общих папок задаются один раз для филиала. При подключении нового компьютера достаточно указать филиал и роль пользователя, чтобы нужные диски появились в Проводнике.

При настройке филиала
Администратор указывает две сетевые папки и буквы дисков. Одна папка предназначена для всех сотрудников, вторая — для руководителей.
После входа в Windows
Если в филиале настроены обе общие папки, сотруднику подключается 1 диск, руководителю — 2. Диски появляются в Проводнике после входа пользователя в Windows.

Для поддержки из той же панели доступны рабочий стол и установленная версия службы. Администратор может опубликовать обновление и проверить, какие компьютеры уже его получили.
